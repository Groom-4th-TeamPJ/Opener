# 오프너

![image](https://github.com/user-attachments/assets/53f6b1d4-cc13-4759-bcc0-abfffabe24a0)

## 📜 프로젝트 소개

수험생을 위한 능동적 수학 학습 서비스 오프너는 단순히 정답을 확인하는 학습에서 벗어나, 오답 이후의 사고 과정을 점검하고 교정하는 데 집중한 수학 학습 서비스입니다. 같은 유형에서 반복되는 오답을 기반으로 AI 튜터가 단계적 질문과 분석을 제공해 학습자가 오답의 원인을 스스로 설명하도록 도와주고 유사·변형 문제로 다시 검증하며 사고 구조를 개선할 수 있도록 설계되었습니다.
