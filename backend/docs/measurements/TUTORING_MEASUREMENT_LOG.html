🐞 발견: 서킷 메트릭 미노출 (수정 적용, 빌드 시 반영)
resilience4j-spring-boot3 만 있고 resilience4j-micrometer 가 없어 resilience4j_circuitbreaker_* 메트릭이 Prometheus 에 노출되지 않았다(Grafana CB 패널 공백 원인). 서킷 기능은 정상(fast-fail latency 로 입증)이었고, 메트릭은 다음으로 해결: resilience4j-micrometer:2.2.0 의존성 추가 + Spring Boot 4 에서 자동 바인딩이 안 되어 TaggedCircuitBreakerMetrics 빈을 수동 등록(ResilienceMetricsConfig). 재측정에서 resilience4j_circuitbreaker_state «104개» 노출 + OPEN→HALF-OPEN 전이 메트릭 확인 — CB State/Failure Rate 패널 정상.
