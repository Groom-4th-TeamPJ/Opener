### D-7. Task 5 — pitch 의 "수치 금지" 규칙을 부분 적용 — **이견**

규칙은 *"수치를 넣지 않는다. 수치는 뒤에서 물어올 때 꺼내는 카드"*.
그러나 계획서가 제시한 초안 자체가 `ai-5` 에 *"4개 발급 경로 중 1곳"*, *"1시간"* 을 포함.

판단 기준을 아래로 갈라 적용.

- **성과 크기 수치(ms · % · 배수)는 전면 금지** — 이것이 "카드로 아껴 둘" 대상
- **구조를 세는 수(경로 네 곳 중 한 곳)는 허용** — 성과 크기가 아니라 *무엇을 발견했는가* 이고,
  이 숫자를 빼면 `ai-5` 의 핵심인 "전수 대조"가 문장에서 사라짐

`ai-5` pitch 에서 `1시간`(access 토큰 수명)은 성과 크기에 가까워 **삭제**하고
*"access 토큰이 끝나면"* → 최종적으로 *"결국 매번 다시 로그인해야 했습니다"* 로 대체.
`ai-4` 초안의 `0.7` 도 같은 기준으로 삭제.

### D-11. Task 14 — `ai-4` 의 원인 진단이 실측으로 반증됨 — **결정 + 최우선 검토**

**이번 라운드에서 가장 큰 발견.** `ai-4` 는 낮은 유사도의 원인을
*"영어 강의자료 + 한국어 질문 조합"* 으로 진단하고 임계값 인하로 대응.
그런데 현재 벡터 스토어는 **5,799청크 중 영어가 4청크(0.07%)** 이고 나머지가 전부 한국어.
**같은 언어끼리도 최고 유사도 중앙값이 0.40** 이므로 언어 정렬은 원인이 아님.

처리 방식 — **진단을 지우지 않고 "반증됐다"고 적는 쪽**을 택함.

- 문제 원인 절: *"당시 원인을 …으로 진단"* + *"이 진단은 뒤에 스윕 실측으로 반증됨"*
- 결과 절: 반증 근거(코퍼스 구성 · 유사도 분포)를 수치로 제시
- **새 원인을 단정하지 않음** — 질문(자연어 요청)과 문서(문제+풀이) 의 형식 차이가 후보이나
  검증하려면 문서 형식을 바꿔 다시 재야 하므로 **가설까지만** 적음

**요검토 3건**

1. 이 서술은 *"진단이 틀렸는데 처방이 통했다"* 를 자백하는 형태. 면접에서 강점(자기 검증)으로도
   약점(원인 미규명)으로도 읽힐 수 있음. **현재 문서는 강점 쪽으로 프레이밍**했으나 뒤집을 수 있음
2. 코퍼스가 바뀌었을 가능성 — 진단 당시엔 실제로 영어 자료가 주였는데 이후 한국어 데이터로
   교체됐다면 **진단은 당시 기준으로 옳았던 것**. 그 이력을 확인하지 못했으므로
   문서는 *"당시 진단"* 이라고만 적고 시점을 특정하지 않음. **사용자가 이력을 아는 경우 정정 필요**
3. 정밀도 37% 는 `metadata->>'type'` 일치 여부를 정답으로 본 **대리 지표**. 사람이 채점한 값이 아님

### D-13. Task 7 — 접힘 구현을 `<details>` + `beforeprint` JS 로 확정 — **결정**

계획서 작업 4는 *"인쇄 CSS 에서 `<details>` 가 펼쳐진 상태로 출력되게 처리"*.
**CSS 만으로는 불가**하다는 것을 렌더로 확인 — `@media print { details > div { display: block !important } }` 를
넣고 PDF 를 뽑으니 **화살표만 ▾ 로 바뀌고 내용은 사라짐**. 닫힌 `<details>` 의 내용 은닉은 `display` 로 못 이김.

두 대안을 같은 PDF 에 렌더해 비교.

| 안 | 방식 | 인쇄 결과 |
|---|---|---|
| **A (채택)** | `<details>` + `beforeprint` 에서 `open=true` | 정상 출력 |
| B | `<input type=checkbox>` + label + 순수 CSS | 정상 출력 |

Chrome headless `--print-to-pdf` 가 `beforeprint` 를 **발화한다는 것을 실측으로 확인**해 A 채택.
마크업이 가볍고 시맨틱하며 계획서가 지정한 형태 그대로.

**요검토** — JS 가 꺼진 환경에서 인쇄하면 유보가 사라짐. PDF 생성 경로가 이 Chrome 하나로 고정돼 있어
현재는 문제 부재이나, **다른 도구로 PDF 를 뽑는다면 B 로 바꿔야 함**. CSS 폴백은 이미 들어가 있으나 무효.

### D-14. Task 7 — 27개가 아니라 14개만 분해 — **이견**

기계적으로 "헤지 단어 포함"으로 세면 27개이나, 그중 상당수가 **자기 취소가 아니라 서술의 일부**
(예: *"전체 건수가 아니라 사유별 추이로"*, *"자원 경합 부재"* 는 긍정 서술).
비판 평가의 정의는 *"결과 불릿이 **자기 취소로 종결**"* 이므로 **종결 절 기준**으로 다시 세어 15개를 얻고,
그중 진짜 자기 취소 14개를 분해.

결과 — 단언부 기준 헤지 **5/55 = 9%** (목표 20% 이하).
잔존 5건 중 4건은 긍정 서술이 헤지 단어에 걸린 것이고, 진짜 자백은 `eco-5` #5 하나로
**Task 8 이 Q5 패턴으로 처리**.

정보 총량은 `difflib` 어절 단위 diff 를 **전수 육안 확인** — 삭제 187어절이 전부
`details` 안에 재등장하거나 어미 조정. **유실 0건**.
