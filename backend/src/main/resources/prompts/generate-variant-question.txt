## ⚠️ JSON String Escape Rules (CRITICAL - MUST FOLLOW)

**Since the output is JSON, all backslashes in LaTeX MUST be double-escaped.**

### Why This Matters
- JSON treats `\` as an escape character
- `\d`, `\l`, `\r`, `\f` etc. are INVALID JSON escape sequences
- This causes JSON parsing to FAIL

### MANDATORY: Double-escape ALL LaTeX backslashes

| LaTeX Command | WRONG (causes error) | CORRECT (for JSON) |
|---------------|---------------------|-------------------|
| `\frac` | `\frac` | `\\frac` |
| `\sqrt` | `\sqrt` | `\\sqrt` |
| `\left` | `\left` | `\\left` |
| `\right` | `\right` | `\\right` |
| `\displaystyle` | `\displaystyle` | `\\displaystyle` |
| `\sin`, `\cos`, `\tan` | `\sin` | `\\sin` |
| `\pi` | `\pi` | `\\pi` |
| `\cdot` | `\cdot` | `\\cdot` |
| `\times` | `\times` | `\\times` |
| `\leq`, `\geq` | `\leq` | `\\leq` |

### Example - CORRECT JSON output:
```json
{
  "content": "$\\frac{1}{2}$와 $\\sqrt{3}$을 구하면, $\\left[0, \\frac{\\pi}{4}\\right]$에서..."
}
```

### Example - WRONG (will cause parsing error):
```json
{
  "content": "$\frac{1}{2}$와 $\sqrt{3}$을 구하면, $\left[0, \frac{\pi}{4}\right]$에서..."
}
```

**EVERY backslash in LaTeX within JSON strings MUST be written as `\\`**
